# お題文

計算に使うテキストです。すべてひらがなに開いた状態で置いてください。

- `wagahai.txt` … 夏目漱石『吾輩は猫である』冒頭 10,872 字（集計用）
- `wagahai_500.txt` … 同じ文章の冒頭 500 字（サイトのタイピング動画用）

漢字かな交じりのままだと形態素解析で読みを振る必要があり、そこで誤差が入ります。
読みを確定させたテキストを用意することで、配列間の比較を厳密にしています。

原文からの変更は `―`（ダッシュ）→ `ー`（長音）の 6 箇所のみです。
`・`（8回）`？`（1回）は原文のまま残してあります。

配列側で未定義の文字は警告のうえ読み飛ばされ、その分だけ打鍵数と距離が
少なく出ます。記号も定義しておくことを推奨します。

`wagahai_500.txt` はサイトの `tools/make_animation.py` が読みます。
片方だけ差し替えると動画と集計で条件がずれるので、変更するときは両方揃えてください。
